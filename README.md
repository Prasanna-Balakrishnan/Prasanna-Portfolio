## 🎨 Theme & Design
The website features a custom **"Red Velvet"** color palette (crisp whites paired with deep reds) and modern UI/UX principles. It includes a sleek, developer-centric hero section with a JSON code card and CSS-only cyberpunk-style graph animations.

## ✨ Key Features
*   **Fully Responsive:** Optimized for desktops, tablets, and mobile devices with a custom hamburger navigation menu.
*   **Dynamic Typing Effect:** A professional JavaScript-powered typing animation in the hero section.
*   **Scroll Animations:** Elements fade and slide into view smoothly as the user scrolls down the page using the Intersection Observer API.
*   **Active Navigation:** The navbar automatically updates to highlight the current section being viewed.
*   **Structured Sections:** Includes dedicated areas for About, Experience, Skills, Projects, Publications, Education, and Contact.

## 🛠️ Technologies Used
*   **HTML5:** Semantic structure and layout.
*   **CSS3:** Custom styling, variables, flexbox/grid layouts, and keyframe animations.
*   **Vanilla JavaScript (ES6):** DOM manipulation, event listeners, and interactive logic.
*   **FontAwesome:** For scalable vector icons.
*   **Vercel:** For fast and reliable hosting.

## 💻 Running Locally
To view this project on your local machine:

1. Clone the repository:
   `git clone https://github.com/Prasanna-Balakrishnan/Prasanna-Portfolio.git`

2. Navigate to the project directory:
   `cd Prasanna-Portfolio`

3. Open `index.html` in your favorite web browser. No local server or build tools are required!
